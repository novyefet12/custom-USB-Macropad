## 🔍 סקירה כללית
פרויקט זה נבנה כפרויקט גמר הנדסי במטרה ליצור מוצר חומרה-תוכנה משולב. המערכת מורכבת מלוח מעגל מודפס (PCB) ייעודי הכולל מטריצת מקשים מכניים, מיקרו-בקר ממשפחת STM32, וממשק USB המאפשר זיהוי המכשיר כמקלדת (HID) ללא צורך בדרייברים חיצוניים.

## ✨ תכונות עיקריות
* **תכנון חומרה מאפס:** סכמטיקה ו-Layout מלאים שבוצעו ב-KiCad.
* **מטריצת מקשים (Key Matrix):** סריקה חסכונית בפינים של מתגים מכניים.
* **תקשורת USB HID:** שליחת פקודות מקלדת ישירות למחשב.
* **קוד Embedded נקי:** מנוהל ברמת ה-Low-Level / HAL עם דגש על יעילות.

## 📐 ארכיטקטורה וחומרה
*(כאן בהמשך תוסיף תמונה של ה-Schematic וה-3D View של ה-PCB)*
* **מיקרו-בקר:** STM32F103C8T6
* **ממשקים:** USB 2.0 Full Speed, Matrix GPIOs.

## 🔄 תרשים זרימה ותוכנה
*(כאן תוסיף תרשים זרימה של סריקת המטריצה וזיהוי הלחיצות)*
התוכנה פועלת בלולאה ראשית (Main Loop) שסורקת את השורות והעמודות במטריצה, מזהה Debouncing (רעידת מגעים), ושולחת את הדיווח דרך ה-USB Stack.
